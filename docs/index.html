ZAP sobre el enlace de Vercel

0 alertas altas, 2 medias, 0 bajas y 4 clases informativas. Revisión pasiva de 14 rutas y recursos publicados, con sesión en la API. Las reglas activas de XSS reflejado y NoSQL MongoDB completaron 22 peticiones sobre limit y page del listado de empleados, sin generar alertas activas.

Las alertas medias corresponden a estilos inline en la CSP y a CORS con origen comodín en HTML, JavaScript y CSS públicos. La API rechazó un origen ajeno con sesión válida; las lecturas de dos cuentas devolvieron su propio perfil y las respuestas privadas conservaron Cache-Control: no-store. No se confirmó una fuga de datos. La aplicación continuó disponible y sus conteos se conservaron.
