# Agents del proyecto SESHA APP

Este archivo describe los agentes o roles que pueden intervenir en el desarrollo y mantenimiento del sistema.

## 1. Agent de backend

- Encargado de revisar rutas, autenticación y lógica de negocio.
- Responsable de mantener JWT, usuarios y seguridad.

## 2. Agent de frontend

- Encargado de la experiencia de usuario, layout, dashboard y navegación.
- Responsable de que la interfaz sea profesional, intuitiva y funcional.

## 3. Agent de pruebas

- Revisa que las pruebas de backend y frontend sigan pasando.
- Valida cambios antes de publicar.

## 4. Agent de despliegue

- Prepara y publica cambios cuando el proyecto esté listo.
- Verifica que los cambios queden guardados y funcionales.
